# 第三十一阶段：操作痕迹分页、筛选与行内详情

本阶段将操作痕迹页改为原型的默认20条数字分页、日期范围、行内展开和顶部直接Excel下载流程。最终2项双端长流程通过，15对有序表格及15对主体布局相同。**P12及全项目完全一致目标仍未完成；完整Excel文件和真实业务审计内容仍有明确差异。** 当前177项注册界面用例没有全量复跑。

## 实际界面检查

两端分别使用既有管理员真实登录，插入相同的54条独立审计样本后，通过页面输入、选择、翻页、展开、下载和语言切换操作验证。夹具直接写入审计样本，仅用于检查显示与筛选；不能据此证明真实业务操作产生了相同审计。

| 场景 | 结果 |
| --- | --- |
| 默认20条、第二页、第三页 | 原始行序分别为54—35、34—15、14—1；再从第一页切换50条，得到54—5 |
| 行内详情 | 点击首行箭头，展开客户、物料、来源订单、批次、请求、转厂、原因、错误、详情和Trace ID；没有弹窗，再次点击收起 |
| 未查询草稿直接导出 | 在50条结果上输入AV00007，仅点击顶部Excel；实际文件包含这一条，原50条查询列表保持 |
| 查询与组合筛选 | 单号关键词一条；分配+失败+页面来源三条；再选不匹配工厂为空；清空筛选可继续查询 |
| 字面关键词与日期 | `%_`按文字搜索为空；实际键入样本日期并查询，当日边界包含样本；点击日期清空后仍可查询 |
| 中、英、越三语 | 真实切换并保存语言，核对相同单行结果和页面；结束恢复中文 |

最终运行49.3秒，workers=1、retries=0；30张截图、15对表格。表格比较所有单元格及原始行序，没有按SN重新排序或替换值。主体测量包含标题、面板、筛选区、表头和首行单元格，15对矩形相同。

详情曾多出18像素，实测为Ant Design默认内边距覆盖及边框模型不同。修正作用域、内边距、行高、边框和展开背景后，本样本20个标签/值单元格的位置、尺寸、内边距、行高、边框及背景均相同。详情JSON仍有冒号后空格差异，未隐藏或归一化为通过。日期输入文字位置、日历图形、侧栏/身份文案等完整像素外观，以及其他宽度/内容长度仍须继续检查；主体矩形一致不等于整页像素一致。
