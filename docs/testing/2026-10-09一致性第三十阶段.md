# 第三十阶段：SN 查询导出拒绝、下载失败与原文件恢复

本阶段修复 P11 导出被拒绝后按钮持续等待、缺少原型具体提示的问题，并补上已提交导出文件的恢复入口。**全项目功能与页面完全一致仍未完成。** 最终一次 6 项双端查询长流程通过；另有 1 项新版持久任务恢复长流程及 2 项提示截图复查通过。均为 workers=1、retries=0；当前注册 175 项界面用例，本轮没有全量复跑。

## 双端界面检查

| 场景 | 实际操作和结果 |
| --- | --- |
| 无权 PI 的 CSV/Excel 导出 | 本厂操作员输入未拥有的 PI 并开启跨厂，在中、英、越三种语言分别点击两个导出按钮；双端真实返回 403，显示对应原型文案，释放按钮等待，并保留原查询两行结果 |
| 修正 PI 后再次导出 | 改为本厂拥有的 PI，实际下载 CSV 的三枚跨厂成员与原型相同；查询列表保持此前两行，导出使用点击时草稿 |
| 下载端 HTTP 500 | 浏览器只拦截一次下载请求并返回 HTML 500；双端显示原型下载失败提示，查询六行保留；通过原导出按钮重试得到六行实际 CSV |
| 既有查询回归 | 合并复跑管理员分页、排序、业务批次、空结果、中英越及 1440/900px，以及三角色范围、组合筛选、拒绝和实际文件检查 |

最终合并回归 6 项一次通过，约 3.4 分钟，68 张截图、34 对有序表格、16 对实际 CSV/XLSX、14 对管理员主体矩形核对通过。表格仅规范化独立生成时间及已分别验证的业务批次身份；文件比较逐列值、类型及原始行序，没有先按 SN 排序掩盖差异，也不声称双端 Excel ZIP 字节相同。

截图复核发现六项合并运行中，部分三秒拒绝提示在等待按钮复位后已经消失；提前拍摄的第一次复查又暴露“可见”断言允许透明动画首帧。最终改为提示出现后等待真实入场动画结束，并确认截图前后祖先累计透明度均为 1；2 项双端复查通过，16 张有效截图单独保留。七对提示逐条验证文案和绘制状态。两次诊断截图都保留，这是相同场景的证据补强，不增加独立业务场景计数。

## 新版持久导出恢复检查

Python 原型同步返回文件，没有新版持久任务、磁盘文件恢复或原操作查询协议。以下一项长流程通过验证新版既有架构的恢复正确性，**不作为这类异常界面与原型完全相同的证据**。

| 故障注入 | 通过真实界面验证的结果 |
| --- | --- |
| CSV 提交未到服务端 | 原操作查询不存在，界面保留未知意图；修改筛选草稿后点击“按原号重试提交”，操作号和完整原请求仍相同，只生成一份导出 |
| Excel 提交已接受、响应丢失 | 服务端已返回接受，再中断浏览器响应和第一次操作查询；刷新页面恢复原任务并自动下载，没有额外提交 |
| 新建 CSV 文件实际丢失 | 只移动本用例刚生成的文件至私有隔离目录，真实下载触发文件校验；刷新后仍可点击“恢复同一文件”，实际下载字节与原文件相同 |
| Excel 恢复已接受、响应丢失 | 原任务恢复已被服务端接受后中断响应；前端重新查询原任务并完成下载，不另建导出 |

该长流程通过，约 34 秒，8 张截图和 4 份实际文件。五次提交请求只形成四份导出，其中两次为完全相同的原意图重试。两份恢复文件的任务号、操作号、快照摘要、数量、字节数及 SHA-256 均保持，仅执行代次增加；恢复前已有的 464 个比较文件逐个摘要未变。

恢复夹具必须先存在严格的查询范围标记，仅允许处理本轮新任务、精确六枚 Q29 SN、11 列格式及对应文件；不移动旧文件。夹具没有代替应用重建文件。正常业务 API 完成恢复后，测试业务 SN、规则、订单和转厂样本已清理；真实审计、任务与固定导出按既定策略保留。

## 代码与验证

- 导出错误改用查询专用三语映射；明确的 400/403/额度拒绝还须得到原操作确实不存在的 404 才能释放意图。网络中断、服务错误或幂等冲突不会仅凭 404 清除原操作。
- 下载失败重新查询原任务；文件状态为失败或待恢复且业务已经成功时，提供原文件恢复按钮。恢复响应中断也只查询原任务。正常页面没有新增提示栏。
- 新增 3 项导出状态单元测试，前端合计 78 项通过；格式、生成类型、lint、TypeScript 和构建通过。大包提醒和 Excel 默认样式提醒仍保留。
- 本阶段未修改后端、验收 JAR 或 SQL，也未重跑 Maven；不能把上一阶段的后端测试数算作本阶段。比较库保持 V33，V1—V33 冻结，下一版本 V34。
- 初次测试包含 HTTP 模板替换错误；修正测试后真实复现“原型通过、新版缺少具体提示并持续等待”。初始失败、修复过程、最终结果及提示补拍分别留档，没有自动重试。
- 原业务、账号安全字段、旧查询快照、旧文件、原型源码及 `sn.env`、第二十六至二十九阶段冻结证据核对未变。两边服务继续运行，无活动业务任务或自有临时夹具。
