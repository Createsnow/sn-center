# 第三十九阶段：账户列表与真实登录信息

账户列表完成一批实际对齐：工号排序、角色/状态/工厂组合筛选、20条分页，以及工厂、创建人、创建时间和最后登录展示。12项双端合并UI用例133.2秒通过，最后同2项账户流程31.9秒通过。**P13账户管理尚未完整验收，全项目功能和页面完全一致仍未完成。**

## 改动和证据范围

| 原有差异 | 本阶段结果 |
| --- | --- |
| 按ID倒序、工号任意位置匹配 | 改为工号升序；工号前缀或姓名包含查询，与原型匹配 |
| 缺角色和工厂筛选 | 增加三业务角色、状态和工厂组合查询；候选账号交集先进入受数据范围保护的SQL，再计数和分页 |
| 目录主要显示部门 | `/users`增加原型八列表格；通用框架入口`/system/users`及既有部门/多角色/多厂能力保留 |
| 缺工厂名称、创建信息 | 系统模块通过framework类型化端口读取SN工厂标签；创建人由不可变工号解析，未跨模块引用Mapper/impl |
| 缺最后登录字段 | V37新增可空`last_login_at`；仅真实成功人员登录更新，与成功审计同事务，校验密码时的版本必须仍有效 |
| 表格、标签和按钮外观 | 对齐字号、行高、内边距、颜色、换行、标签和20条分页；中文/英文/越南语已检查 |

两端各通过真实API新建27个独立账号，以工号倒序创建，包含24个厂区操作员、2个查询员、1个管理员，其中2个停用；以此区分按工号排序和按创建ID排序。实际界面检查首/末页、角色筛选后返回第一页、角色+状态+工厂空交集、清除筛选、姓名包含、拒绝工号中间片段、三语切换。另以新管理员账号从登录页登录，进入首次改密页，然后在账户目录确认最近登录出现。没有修改任何旧账号密码。

最终12对页面状态中，表头及6个业务列原始文本相同，页面卡片/工具栏/表格/分页四组几何相同；采集到的状态标签与行内按钮尺寸和样式相同。创建时间和最后登录时间来自两套独立测试的真实操作，未强行改为相同：逐行分别核对各自实际API。创建人同为admin；这是已覆盖列表状态的验证，**不代表全屏逐像素相同或全部按钮业务完成**。最终英文界面已进行视觉复查。
