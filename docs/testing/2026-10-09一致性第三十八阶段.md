# 第三十八阶段：首页快捷入口与顶部身份栏

本阶段修复英文快捷按钮换行、顶部工厂/语言/用户区、面包屑及窄屏卡片间距。20项合并界面流程201.5秒通过；追加同2项流程补查滚动和返回，最终27.2秒通过。工厂操作员三语/四宽度及滚动后的15对状态，28组几何/样式和1组表格分隔线样式均相同。**这是已覆盖状态的进展，全项目完全一致仍未完成。**

## 今日数字为什么不同

真实API和页面数值与各自独立测试库的成功审计事实逐项核对通过。当前甲厂范围：

| 动作 | 原型 | 新版 |
| --- | ---: | ---: |
| 领取 | 1604 | 1636 |
| 分配 | 2150 | 2059 |
| 生成 | 2150 | 2059 |
| 打印 | 737 | 655 |

全厂范围也通过现有管理员页面与只读审计求和检查。当前日期有原型1007条、新版933条相关成功事实；按动作/工厂/PI分组有15组数量不同。例如`CMP-UI-QUERY-PI-A`领取原型6条/306枚，新版8条/408枚；历史反复运行和失败诊断没有执行相同次数，真实审计从未为了让数字相同而删除或改写。本次证明当前页面反映各自存储事实，不证明此前所有动作的审计生产逻辑均完全一致。

源码还存在日期边界差异：原型只限制“今天零点以后”，新版同时限制“小于明天零点”。当前相关未来日期事实为0，所以这不会解释当前数字差额；该边界仍待专门验证和对齐。分组明细见[统计核对](evidence/parity-20261009-stage38/stage38-statistics.json)。

## 回归范围与失败诊断

一次20项合并201.5秒通过：新增首页/顶部布局2项、既有四角色及首页语言10项、登录布局2项、改密6项。workers=1、retries=0，无失败或跳过。18对登录/15组、33对改密/15组和3对稳定成功提示再次相同。既有角色用例标题包含“首次改密”，本次已保存changed状态，未重新修改这些账号密码；实际检查现有新旧凭据拒绝/接受及菜单/范围，不冒称再次首次改密。

初次布局导航虽通过，测量发现字体、间距和窄屏偏移，三个诊断版本均保留。20项之后视觉复核发现内部滚动使最后一个按钮在截图之外，同时发现表格横线颜色不同，于是补强滚动/点击和边框测量。

首次补强原型180秒超时；结束清理又因页面关闭报错，遮住直接等待点。后续独立记录证实原型折叠菜单中按“工作台”名称查询为0项，新版为1项。先验证浏览器返回，2项25.1秒通过；再按已核对顺序直接点击第一个工作台图标，最后同2项27.2秒通过，两种返回路径均已验证。保留可访问名称差异，不将原型未找到名称包装成产品接口失败或完整无差异。

20个独立用例已执行，追加均是同2项增强检查，不计为新增独立用例。最后产品改动仅表格边框色；20项在该颜色改动前运行，追加2项覆盖最终首页样式。201项注册UI未全量复跑。

78项前端单元、API类型一致性、lint、构建、格式/-Check通过；最后样式后重新lint/build，最后测试补强后再格式/-Check/lint通过。后端未改、未重跑Maven。已视觉查看双端英文1440、越南语390和滚动后画面；超窄屏面包屑仍沿用原型的换行/裁切表现，不称其布局理想。
