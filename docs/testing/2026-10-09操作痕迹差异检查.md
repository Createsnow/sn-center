# 操作痕迹：双端页面初查

第三十阶段查询检查归档后，使用本机比较环境的既有管理员，通过浏览器实际登录、点击“操作痕迹”、打开第一行详情。两个系统均可访问，下面的差异已复现，**P12 尚未通过一致性验收**。本次只是只读观察，没有新增正式验收用例，也没有把页面打开成功视为功能通过。

| 项目 | Python 原型 | 新版当前行为 | 后续处理 |
| --- | --- | --- | --- |
| 默认分页 | 每页 20 条，数字页码、总数与条数选择 | 每页 50 条，上一页/下一页游标 | 对齐页码、每页条数和筛选后复位；保留当前权限约束 |
| 页面结构 | 说明为“痕迹永久保存”，筛选和表格同一白色容器 | 较长说明、筛选置于标题区域、保留说明另占一行、记录页签 | 按原型统一结构、文字、间距和表格密度 |
| 日期筛选 | 一组起止日期范围选择器 | 两个原生日期输入框 | 对齐选择、清空、默认范围、日期边界及查询请求 |
| 详情 | 点击最左侧箭头，在表格行下展开三列详情 | 最右侧“明细”按钮打开弹窗 | 对齐展开/收起、字段、空值和换行；检查长内容及多行展开 |
| 导出入口 | 标题右侧“导出 Excel”，直接下载当前草稿范围 | 表格前 CSV/XLSX 按钮、确认和任务/历史入口，使用已查询条件 | 对齐主流程；实际文件字段、时间、数量、顺序和错误恢复另行验证 |
| 额外筛选 | 页面无存储来源选项，来源提供页面/API/系统 | 有在线/归档选择和额外 MES 来源 | 对齐原型可见筛选，后台权限与归档数据仍按契约处理 |
| 表格 | 展开列 + 时间等 11 个业务列，工厂显示名称 | 11 个业务列 + 操作按钮列，部分空值、时间和动作文本不同 | 用相同业务触发逐字段检查，避免仅比较外观 |

本次两边已有审计数据来自不同轮次的独立测试，不能直接比较总条数或第一行内容证明业务一致。原型首页列表出现登录事件、新版 SN 痕迹出现任务快照/文件动作，也提示需要进一步核对相同操作应产生哪些用户可见审计；尚未把这些差别判定为已修复或允许的豁免。

证据含双方页面和详情四张截图、对应界面文本，以及源码摘要：[观察摘要](evidence/parity-20261009-audit-observed/summary.json)、[文件摘要](evidence/parity-20261009-audit-observed/manifest.json)。前两次诊断分别存在页面切换未完成/按钮文案定位错误及入场动画问题；最终等待准确页面标题、加载结束和真实动画完成再记录，诊断失败不计为产品缺陷。

后续从分页、筛选、展开详情和导出实际行为开始修复，补建同一业务输入的双端界面检查，再覆盖全部角色、归档、错误、时间边界及三语外观。查询页其他未完成边界与 [P01—P16 完整范围](SN页面与功能一致性验收清单.md)继续保留。
