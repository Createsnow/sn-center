# SN 一致性第二十四阶段：转厂订单快照选择

2026-10-09。本阶段对齐 P10“从订单快照选择”，并通过真实页面验证快照回填和实际转厂。最终一次合并回归 **10/10 通过**，约 5.8 分钟，单工作器、零自动重试。**完整一致性目标仍未完成**；原型物料缺陷及其它待验项目没有因本轮检查通过而关闭。

## 修改内容

- 快照弹窗调整为原型的 820px 宽、360px 表格区域，显示生产组织、客户、PI、物料编码、物料名称，点击整行回填。取消额外的选择按钮、搜索按钮和分页控件，每次显示前 50 条；原型路由实际传入的限制是 50，并非服务函数允许的最大 200。
- 后端新增独立快照投影 `TransferSnapshotVO`；保留未映射组织，工厂 ID/编码/名称共同为空。过滤空客户及空 PI，按组织/工厂、客户、PI、物料合并，名称取最大值。支持 PI、订单号、物料编码和客户搜索，通配符按字面值处理；按 PI、物料排序。接口仍保留完整分页，页面按原型显示首批候选。
- 工厂手填目录与快照目录分开，原有启用工厂选择和 `sn:transfer:targets` 权限检查保留。目录不包含库存数量，也不授予其它工厂库存访问权。组织仍采用已批准的 ERP 稳定映射；工厂改名或映射变化组合尚未证明与原型的名称连接完全相同。
- 关闭再打开保留输入和候选；回车重新搜索，包括回到曾经使用的条件。点击快照标记 `SNAPSHOT`，手工修改目标改为 `MANUAL`；未映射行回填其余字段并清空旧工厂，不能据此提交。
- 修正截图检查发现的标题绘制问题：标题虽有文本及可见 DOM，原先截图未绘出文字；调整标题区域层级后复查可见。七组弹窗位置、宽高一致，并检查真实截图标题区域存在文字像素，未将 DOM 可见等同于已绘制。

## 页面验证

新增双端测试通过页面全量同步导入五张专用合成订单、59 条分录。原订单保持，检查结束后通过页面恢复为三张单据、四条分录；专用未用快照在严格所有权检查后清理。

| 场景 | 本轮实际检查 |
| --- | --- |
| 首次打开 | 五个表头、50 条候选、无分页及额外搜索按钮；820×477 弹窗与原型同位置 |
| 搜索 | 空白裁剪、含 `%_` 的订单号字面搜索、客户、PI、物料；物料名称不作为搜索字段 |
| 超过首批 | 找到首批 50 条以外的 `PICK-M054`，未通过增加页面上限绕过原型行为 |
| 合并 | 同组织/客户/PI/物料跨单去重，名称取最大值；按订单号过滤后名称来自匹配分录 |
| 行选择 | 整行点击关闭，工厂/PI/客户/物料回填，手工改目标后来源切换 |
| 未映射及空值 | 显示未匹配工厂提示；选择后旧工厂清空；空客户、空 PI 不进入候选 |
| 条件保留 | 关闭重开保留搜索；输入清空后按回车恢复；重复条件及已缓存条件仍实际请求 |
| 实际提交 | 三次转厂往返的最后一步，从快照选入并整批转回原厂；检查请求和保存记录均为 `SNAPSHOT`，随后重新领取、打印和下载 |

最终十项合并检查由两端各五项组成：上述快照选择、转厂往返与打印、转厂表单、角色入口、51 枚 SN 的申请/撤回/驳回/批准闭环。物料表单分支继续记录原型空参数导致的 400；这部分测试通过表示缺陷被准确记录，**不表示物料功能双端一致**。
