# SN 页面与功能一致性验收清单

目标：将 `adtek-platform-sn` 的 SN 功能、页面、交互和用户可见结果对齐同目录的 `sn-center-python`，通过浏览器逐项操作证明。2026-10-08 开始，目标仍在执行中。

Python 基准为本地提交 `f8bc2d722cfde38cfb3ee892a50dcd1d90d58a4a`。目标工程起点为 `46f607c936ab3b2deef5e025edd87f2e0e31dc88` 及前次比较报告。保持 React、Spring Boot、MySQL 工程约定；原型、已有业务库和历史资料不修改。全部写操作使用本机独立比较数据，不连接公司 K3 或 GitLab。

## 验收规则

- 逐项检查页面的名称、布局、字段、默认值、列表列、排序、筛选、分页、按钮、弹窗、确认、成功与错误反馈，以及刷新和返回后的行为。
- 同一组合成数据在两边通过界面提交；记录界面结果，并核对下载内容及必要的后端状态。API 测试可以辅助定位，不能替代按钮操作。
- 总部管理员、厂区操作员、总部查询员和绑厂查询员分别检查可见入口、操作限制及数据范围；三种语言与窄屏也纳入检查。
- “一致”必须有当前修改后的浏览器证据；代码存在、旧报告通过或页面能打开均不足以完成一项。
- 2026-10-08 前次报告中的小数数量、历史打印、排序和布局差异都继续列为待对齐，不能用原有差异说明直接豁免本次目标。
- 内部安全机制、持久任务和精确字符串传输可以保留，但不能改变要求一致的操作流程和业务结果。对外 MES 功能也必须有相应兼容与验证证据。
