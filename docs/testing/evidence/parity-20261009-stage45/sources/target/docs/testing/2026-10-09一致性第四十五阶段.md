## 仍须继续，不能据此认定完全一致

1. ERP内码不变而编码变更、内码替换、同名组织去重、禁用/异常目录，与原型仍不同。不能只修工厂表：原型按订单快照中的组织名称找工厂，而新版按内码投影，改名/改码会影响旧订单归属及可生成状态。显式映射扩展也必须一起核对。
2. 全量订单中组织发布与订单发布的事务边界、完整K3故障类型、权限拒绝、并发、加载失败、等待与焦点、长冲突详情和更多语言/视口继续验收。此次未以10条工厂事实覆盖这些组合。
3. 共享工厂目录在查询、领取、转厂等其他页面的名称变化传播仍要逐页核对；P13剩余账户边界、P01—P16完整矩阵、早期行序、容量/恢复及全UI业务闭环继续执行。
4. 返页滚动位置在本轮实拍中仍不同，需要后续按真实导航路径修复和检查；已测逐字位置采用相对单元格坐标，没有用它宣称页面滚动状态一致。

全部历史阶段的证据保持只读；本轮部分通过不代替完整目标验收。
