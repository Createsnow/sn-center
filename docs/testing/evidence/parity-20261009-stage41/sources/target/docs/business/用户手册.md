# 当前可用功能

维护日期：2026-10-09。本文为当前说明；本轮规则见[SN补迁契约](SN补迁契约.md)，验证和未完成项见[当前发布记录](../releases/2026-10-04本地交付.md)。历史阶段原文已另行冻结归档。

本手册覆盖账号、系统配置、审计和 SN 工厂、订单、规则、生成、分配、领取、打印、转厂、查询与工作台。当前为本地功能交付，生产启用仍需完成发布边界中的验收。

1. 打开 http://127.0.0.1:15173 。登录页右上角可选简体中文、English、Tiếng Việt。
2. 使用工号登录。本机账号 admin 已完成首次改密，请使用当前密码。deploy/.secrets/bootstrap-admin-password 的初始值已失效；普通启动不重置密码。
3. 首次登录会进入设置新密码页面。输入当前密码、新密码和确认值；新密码需 8–64 个字符，包含英文字母和数字。成功后直接回到首页，服务器返回新会话，所有旧版本会话失效。
4. 在个人设置查看姓名与工号，选择界面语言。保存到账号后，下次登录继续使用。
5. 通过账号安全进入修改密码；修改后全部旧版本会话失效。初始密码文件不会自动更新，不能把旧值当作当前密码。
6. 点击退出登录撤销当前会话；同源其他标签页会返回登录。刷新页面使用 HttpOnly 会话凭据恢复，过期后需要重新登录。

请求过于频繁时按提示时间等待。服务暂时不可用时保留错误追踪号，稍后重试；界面不会把未确认的操作显示为成功，也不自动重复提交写入。

## 用户管理

完成首次改密后，有 system:user:list 权限的账号可从侧栏进入“用户管理”。支持按工号/姓名搜索、启停状态筛选及分页。按钮按操作权限展示，提交仍以服务器当前权限和范围校验为准。

- 新增：填写唯一工号、姓名、有效部门、初始密码。具备安全管理权限时可选已有角色；角色对应的五类部门范围显示在选项中。新账号首次登录必须改密。
- 编辑：可改姓名、部门及授权范围内的角色，工号保持不变。角色范围定义在“角色管理”维护。编辑本人后会退出，使用当前密码重新登录。
- 停用/启用：确认后生效，历史身份保留。不能停用本人；至少保留一位启用的平台安全管理员。
- 重置：为其他账号设置临时密码，旧会话立即失效，下次登录必须改密。本人改密使用个人设置；不能重置权限超出自身管理范围的账号。

SN侧栏“账户”使用三角色表单，编辑姓名、角色或工厂后保留登录。服务器下一次请求立即按新权限检查；刷新页面更新顶部身份、菜单及工厂范围。相同筛选条件再次查询会读取最新列表，便于看到其他窗口的编辑。扩展角色/多厂账号使用通用管理表单，其会话撤销规则仍按上文执行。

“账号已被其他操作修改”表示页面版本过期，刷新列表并核对后再提交。密码只输入、不回显；请通过你们既有的安全方式交给账号使用者。当前没有自助找回密码；不要用重复初始化命令恢复已有管理员。

## 系统配置

配置管理员需同时拥有对应 list/update 权限和 system:security:administer，且两者部门范围均为“全部”。局部用户管理员不能维护全局配置。侧栏提供角色、部门、菜单和字典管理，支持搜索与分页显示。

- 角色：新增唯一编码和名称，选择五类部门范围、工厂范围、菜单/操作权限；“自定义部门”可为空，表示空部门范围。编码不可修改。编辑中切换到其他范围会清空自定义部门关联。共享角色只能授予自己拥有全部部门范围的权限；工厂资格另行校验，不能凭平台角色名称扩大工厂权限。
- 部门：选择上级或留空建立根节点；编辑可移动节点。不能形成循环，也不能停用仍有启用子部门或启用用户的部门。
- 菜单：目录 M、页面 C、操作 F；页面只能从已发布组件中选择，不能填写代码或任意地址。类型和权限标识创建后不可改变；父目录存在启用下级时不能停用。新业务权限随对应后端功能发布，配置页不能创造后端能力。当前已发布组件包括操作日志。
- 字典：先新增类型，再进入“管理字典值”，填写唯一业务值、中/英/越名称和排序。类型编码和值不可修改；停用类型后保留原值，但不能编辑其值，重新启用类型后可继续维护。显示名称随个人界面语言切换。

每个配置目录最多 1000 项，单角色菜单/自定义部门最多 100 项；超限会明确提示。版本冲突需刷新后核对重填，系统不会自动覆盖。授权变更使相关账号旧会话立即失效；若影响本人，保存成功后回到登录页，使用当前密码重新登录。至少保留一个有全部部门范围的安全管理员。

## 操作日志

完成首次改密且拥有 system:audit:list 的账号可从“审计日志”进入。默认显示最近7天，支持起止时间、操作者工号、动作、模块、成功/失败和追踪号筛选。时间按浏览器本地时区输入和展示，起止需成对填写，单次最长31天；可以查询更早的指定窗口。重置恢复默认筛选，刷新重新读取当前条件。

列表总数与详情遵循角色授予的数据范围。“仅本人”只显示自己的记录；部门范围按日志写入时的部门快照判断。旧记录没有部门快照时，不按操作者现在的部门推测归属。动作与模块选项同样限制在可见范围内。

“查看详情”显示准确日志编号、操作者、发生时间、结果、追踪号、请求模板及允许展示的字段变化。可复制追踪号供排查；密码、令牌等秘密不作为详情字段。历史内容不符合展示规则时会提示部分内容已省略。失败表示请求未正常完成，不保证所有外部动作或事务都已撤回，请核对后再处理。

当前支持在线日志查询和下述CSV导出，尚无归档检索、编辑或删除入口。总数保留精确值，页面最多浏览10000页；记录过多时缩小时间和筛选条件。操作类型或模块选项超过200项时也需缩小时间窗口。

## 日志导出与恢复

同时有日志查询和 system:audit:export 权限时，日志页下方显示“导出任务”。先点击“查询”应用筛选，再点“导出 CSV”；按两项权限可见范围的交集固定快照，最多10000行/16MiB，超限需缩小范围。默认时间窗在点击时固定为最近7天，此后重试不会漂移。

排队/执行时页面显示任务、操作号和进度；进度不是已生效的业务数量。文件可下载后点击“下载 CSV”。该格式用于程序交换，电子表格打开时应将ID列按文本导入，避免自动舍入；当前没有XLSX。以后新增或修改日志不会改变这份固定文件。

提交超时显示结果待确认，点击“查询原操作”；本次页面还保留输入时可“按原号重试提交”。刷新页面可从当前账号保存的操作号恢复。不会自动换号重做。只保存每个账号最近一项导出的UUID；换浏览器/清除站点存储前请保留操作号，当前没有任务历史列表或管理员跨用户查询页。

仅未被工作器领取的排队任务可取消；已执行、重试等待或文件恢复周期不提供业务取消。停止轮询、关页和断网都不取消后台任务。“创建另一份导出”需要确认新的意图，旧任务仍保留。

已成功的文件丢失或校验失败后，会提示“恢复同一文件”，恢复仍使用原快照、任务号和文件号。权限减少或账号停用后原文件也可能无法下载，拥有文件并不绕过当前权限。V6升级撤销原平台管理员旧会话时，使用当前密码重新登录，不重新初始化账号。

## SN 工厂、订单与规则

工厂页沿用编码、名称、来源和更新时间。可“手工新增”或“从金蝶同步”；同步返回新增/更新数和冲突。手工工厂与ERP同名不自动关联，核对后用“关联生产组织”选择稳定组织。同一组织不能改派；没有配置ERP时显示明确错误。

生产订单页保留全量/按单据同步、最近同步信息和未建档提示。左边按订单汇总，右边点击后显示PI/PO/客户/工厂及物料分录；同物料多行和空物料照常显示。按单据、PI、PO、物料、客户或工厂筛选，不显示空客户订单。全量/单据同步失败保留当前有效快照，可在“同步记录”核对结果。历史生成累计与当前可生成额度不同，订单减少或分录消失不清除历史。有生成页面权限时，“去生成”携带当前来源订单进入预演和生成流程。

规则页保留通用/客户/PI绑定和搜索。新建输入编码、名称、绑定、前后缀、进制、位数和字符表；默认字符表留空，实时样例和最大流水显示精确值。编码和绑定创建后不改；改名不新增版本，未用编码参数就地改，已用编码参数新建版本。“版本”查看历史编码；历史已发号不改变。成功生成和可解析导入会在业务事务内标记规则已使用。

同时有安全管理与工厂分配权限时，用户编辑弹窗可选择多个显式工厂；空集合表示没有工厂资格。角色的“全部工厂”资格独立，不能把空选择理解为全厂。绑定变更撤销该用户旧会话。无工厂分配权限的编辑保留原绑定；服务器仍按每个操作检查委派上限。

## PI 起始号与历史导入

打开“起始号与历史导入”，查询PI，核对快照、客户、规则和当前流水。尚未锁定时可填高于当前可解析外来号的十进制起号、粘贴清单或上传UTF-8 CSV/TXT（取首列）；清单重复会阻止提交。可选工厂/客户/物料按旧页语义填写。确认后查看任务结果，成功的历史号为已打印；无法按规则解析的号保留原文且无流水。PI只允许在首次生成前一次初始化，成功后不能改起号。

## 准备号与整单分配

从订单页“去生成”或“生成与分配”按客户、PI、订单选择。未绑定 PI/客户且从未成功选择规则时，先选择规则；成功后沿用。切换订单或浏览器前进/后退会清空上张订单的局部输入与预演。核对来源订单、分录、规则、PI流水和汇总。数量默认取可用额度与页面建议10000的较小值，可调整建议量；起号只在PI未锁定时显示。先预演核对完整起止SN、十进制范围和各分录号段，再确认生成。修改数量/起号须重新预演；后台同时检查快照、规则、额度与有效期。

生成成功后第二步显示全部待分配数量和固定生产组织，数量不能拆分。确认后整批变为待领取；后续增量生成可再次整体分配。组织/PI变化或计划量低于已消耗量会明确提示，需要先核对来源。历史表可翻页；操作号、进度和终态保留在页面。

刷新或网络响应不明时先点“查询原操作”，同意图重试保持原操作号。进度不代表已提交数量；失败会整批回滚，需重新预演或修正输入后提交新意图。领取、打印和 MES 契约见下节。

## 领取 / 打印

进入“领取 / 打印”，按工厂、PI查询；物料“全部/无物料/指定物料”和状态仅筛选连续段。点击PI可聚焦，开启“同PI跨厂”仅查看分布，所有写按钮收起。查询角色可以查看当前授权工厂的批次和历史打印文件。

“领取”处理该工厂+PI全部待领取号；确认后查看可领/阻止数量及逐项原因。零可领也是已完成结果，不生成空批次。结果未知先查询原操作，刷新仍使用原号。领取批次明细显示仍属于该批次的当前成员及状态；转出或重新领取的号不再显示，历史列表上的原领取数量保持不变。回调和审计所用原始成员仍保存在后台。

“打印”确认该工厂+PI全部待打印号为已打印，并自动下载 XLSX。打印记录中的 CSV/XLSX 每次按该打印单当前仍包含的号码生成：转走的号码从旧文件消失；全部转走时下载只有表头；转回后重新领取、打印归入新记录，旧文件不会重新包含这些号码。记录上的原打印数量保持不变。下载失败可在打印记录中再次下载，无需再次确认打印。XLSX 的业务编码保留文本，序号及十五位以内整数流水使用数值，长整数保留文本。下载不修改 SN；使用已保存的旧标签前仍需核对当前归属和状态。

自动或历史下载失败会显示约三秒的错误提示；已完成的打印不会回滚，批量操作仍继续处理其他 PI。可从打印记录重新下载，重下不会新增打印记录或修改 SN 状态。非 JSON 的 HTTP 拒绝会显示状态码，有效业务错误保留对应提示。

批次/打印历史每页 10 条；点击“详情”打开六列明细，按流水归属、十进制流水和创建顺序排列，每页 50 条，可用数字页码翻页。列表均显示总条数，重新打开详情从第一页开始。界面支持中/英/越。MES 不使用人员登录，管理员按[独立凭据契约](MES领取与打印契约.md)配置调用方。

## 转厂、查询、操作痕迹和工作台

“转厂”先选来源工厂/PI，再选整PI、物料（空为无物料）或完整SN并查询候选。填写转入工厂/PI及原因；客户/物料留空表示逐枚沿用。可从生产快照挑选目标，也可手工填写。工厂提交申请后SN为申请中；总部确认转入，或驳回恢复原状态；有来源工厂撤回资格的操作员可撤回。记录页保留方向、状态、数量和固定明细，旧批次/打印记录不会消失。已打印实体标签由现场另行处理。

“SN查询”支持工厂、PI、物料、客户、状态、完整SN、来源订单和业务批次号。空白物料表示不限物料；默认每页20条，可选择50/100/500条。未指定PI时按创建顺序倒序，指定PI时按物料及原流水排序。“同PI跨厂只读”只开放该PI的查看，不授予其他工厂写入或旧文件权限。

页面顶部“导出Excel”和“CSV”使用点击时的输入，即使尚未按“查询”，也按新输入导出全部匹配结果。文件准备好后自动下载，包含原型11列；空结果仍返回表头。下载请求失败可重下原文件，结果不明先查询原操作。旧22列文件保留原字节。更多角色、文件丢失后的界面恢复和原型末页改条数竞态仍在验收，详见当前一致性清单。

“操作痕迹”显示操作时的人员/工厂、数量、SN边界和状态变化。默认最近30天，可选日期和在线/归档；转入厂可读关联转厂历史。详情显示操作号、批次、原因、错误码和请求追踪号。CSV对姓名/原因等自由文本防公式解释，XLSX保留精确文本。平台认证/配置/入口安全日志仍在“操作日志”。

“工作台”显示本人当前范围的在途、待审批、今日作业和最近生成任务，30秒刷新；无权限的全局累计不显示为零或泄露数值。全部页面支持中/英/越和手机布局。

## 定时同步、起号提示与登录锁定

拥有全部工厂同步资格的人员可以保存全量同步开关和 10—10080 分钟间隔。页面显示下一次执行、最近结果及最近成功量；关闭或改设置使未提交的旧执行失效。保存者被停用、被撤权或需改密后，定时执行不能继续借用旧权限。默认关闭，不配置 K3 时不会显示虚假成功。

生成会避让按当前规则能够解析的转入号及原未解析导入号。例如先导入 G0600 后采用 G+四位规则，建议从 G0601 开始。转厂确认/审批窗口显示目标起号与空档参考；局部工厂账号看不到目标全 PI 水位。提示不是锁定结果，提交时仍检查，完整 SN 碰撞整批回滚。

十五分钟内连续输错五次后锁定十五分钟，第六次包括正确密码也会拒绝；到期后重试，成功登录清零。请按提示等待，勿通过重复初始化重置已使用账号。
