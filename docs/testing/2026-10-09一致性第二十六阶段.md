# SN 一致性第二十六阶段：转厂表单与三语布局

2026-10-09。本阶段继续 P10 转厂页面对齐，集中处理第二十五阶段截图中发现的尺寸、间距和图标差异。一次 **22/22 双端合并回归通过**，约 8.1 分钟；关闭图标基线最终修正后追加 **6/6 三语布局复查通过**。均为单工作器、零自动重试，复查没有重复计为新增用例。**完整一致性目标仍未完成**。

## 实际修正

- 以浏览器测量为依据，修正标题继承行高、表单标签行盒及每栏最后一个字段的间距。原型字段间距来自 14px 外边距和 4px 表单间隔，最后一项没有额外 4px；新版分别处理，避免行数越多偏差越大。
- 统一成功/警告提示的图标尺寸、垂直居中、文字间隔、字号与状态标签基线。带说明的图标为 28px，单行提示图标为 16px。无可转成员时的说明沿用警告色。
- 取消文本域多余的外层边框厚度和外发光，保留原型的内描边和聚焦反馈；三行文本域高度为 73px。单选按钮采用相同字重、内边距与轮廓，同时保留键盘聚焦提示。
- 在 900px 视口中，来源和目标上下排列时移除额外的 24px 网格行间距；每栏实际坐标与原型逐项比较。
- 输入框继续支持清除，仅在悬停或聚焦时显示图标。**没有删除清除功能**：复查源码确认原型也配置了 `clearable`，先前静态截图中的图标缺席来自显示时机。
- 快照弹窗恢复 48×48 的关闭点击区，使用原型同形关闭、搜索、清除图标。新增固定 SVG 路径来自本机已安装的 Element Plus Icons 包，沿用同目录 MIT 许可，不接受运行时 HTML 输入。

所有样式限制在转厂表单和快照弹窗。没有改动后端、SQL、旧库或原型源码。复查快照组织列的计算颜色后确认两边原本均为 `#606266`，没有仅凭截图观感改成另一种颜色。

## 页面检查

新增测试在中文、英文、越南语各运行一次原型与新版，使用现有合成基线只读查询，不执行转厂提交。语言修改走真实设置接口，结束后恢复简体中文。

| 检查 | 实际操作与断言 |
| --- | --- |
| 空表单与有效条件 | 检查初始不可提交；选择来源/目标工厂，填写 PI 和原因，等待真实候选与起号提示后可提交 |
| 清除输入 | 鼠标移出并失焦时隐藏清除图标；悬停显示，点击清空来源 PI 后提交禁用；重新输入后恢复 |
| 整 PI 与单号 | 记录整 PI 布局；切换单号并填写实际存在的 `CMP00002`，检查候选和按钮有效 |
| 三语与两个宽度 | 1440px、900px 视口；记录标题、表单行、文本域、单选按钮、提示框、图标和规则说明的实际矩形 |
| 快照弹窗 | 搜索 `CMP-PI-001` 返回两条分录；五列表头及行内容/顺序核对；记录弹窗、搜索框、关闭区与图标矩形 |
| 关闭保留 | 点击实际关闭按钮，返回单号表单仍保留输入；没有用修改 DOM 隐藏弹窗来替代用户操作 |

截图与矩形测量分别保存。矩形比较不截断小数、不增加容差、不移动截图；这只证明声明测量的元素一致，不能推导为整个页面每个像素或所有交互状态完全相同。

## 诊断与剩余范围

第一次三语检查全部通过后，独立矩形比较发现六组快照关闭图标均向下偏移 2px。单纯居中 flex 未解决偏移，22项合并操作通过后，布局比较仍准确报告该差异。继续测量确认原型按钮使用浏览器默认 Arial 字体和行内图标基线，而不是几何中心；最后还原按钮字体、默认行高和基线，追加六项三语复查。未通过增加比较容差或偏移截图绕过。22项运行时的原始布局截图/测量保留在 `diagnostics/layout-before-final`，最终六项布局证据保存在 `ui`，两轮原始结果均保留。

900px 截图仍显示公共导航折叠方式不同：原型保留被裁切的分组/文字，新版仅显示图标，这是 P01 的待对齐项。页签、按钮文字的字重/细节、窄屏下部滚动操作、其它宽度、不同角色和转厂状态仍须进一步验收。原型首次物料选择的空参数 400 继续单独留证，未视为一致通过。P10 跨 PI 审批、长历史、并发/恢复，快照错误/乱序/身份变化/改名；P09 剩余权限/恢复/旧文件/容量，以及 P01—P08/P11—P16 和 50 万导入性能差异继续保留，见[完整清单](SN页面与功能一致性验收清单.md)。
