# 第三十七阶段：改密表单与真实操作

本阶段修正改密页校验时机、强制改密告警、字段/按钮样式、密码显隐和成功提示。最终14项双端界面流程215.6秒通过，三语33对改密状态的15组测量相同。**这证明已检查状态的进展，全项目完全一致尚未实现。**

## 修改及覆盖范围

| 原差异 | 修复及实际验证 |
| --- | --- |
| 输入中立即校验，确认密码在新密码输入时自动重验 | 与原型一致改为失焦/提交校验；真实输入短密码、不一致确认、修正后再失焦，检查错误出现和消失的时机 |
| 必填标记、标题/字段字体、眼睛与空后缀占位不同 | 原型字体、字号、星号、输入高度、边框/阴影和SVG显隐图标；空字段隐藏后缀，真实点击显示/隐藏演示密码 |
| 强制改密告警图标、文本边距和窄屏换行不同 | 修正图标尺寸和左右内边距；英文390px原有多出一行已修复；加入可见告警文字逐字矩形比较 |
| 错误下方多出20px位置、1px边框缩小输入 | 错误采用原型12px字体、绝对定位、相同颜色；移除Ant额外最小高度与错误边框 |
| 按钮间距与成功提示位置/字体不同 | 采用原型按钮布局；全局成功提示保留跨页面显示，局部修正字体、14px图标、行高和顶部16px位置 |

新增6项UI用例：中文/英文/越南语各在原型和新版操作。每项使用新建隔离账号完成强制改密、退出重登、真实保存、回首页、账户菜单主动改密及取消返回。空提交不发送改密请求；真实保存各恰好一个改密请求。没有修改原管理员或既有角色账号密码。

每种语言采集11种状态：强制改密1440/900/390px，短密码输入中/失焦后、不一致确认、修正完成、演示密码显隐、空提交，以及主动改密1440/390px。均高960px。33对JSON原样比较，15组为外层、面板、标题、告警/图标/文字、表单、标签、字段、实际输入、眼睛、策略说明、错误、操作区和按钮；告警文字另含逐字矩形。三对成功提示在截图前后均完全可见，稳定后的几何、颜色和文字相同。未主张全屏逐像素相同。
