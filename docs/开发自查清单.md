# 开发自查清单

用于学习或开发新功能时自行核对，无需另找执行者、填写验收表或提交练习记录。本轮指南交付已经完成，本清单不作为额外完成条件。

从[学习指引](03-开发人员学习指引.md)进入，按[创建指南](02-新项目创建指南.md)启动，再参考[设备样板](04-业务开发样例.md)开发。

| 核对内容 | 判断方法 |
| --- | --- |
| 独立环境 | 新目录、空库及独立端口完成初始化，登录后修改初始密码 |
| 完整功能 | 列表、详情、新增、编辑可以从真实页面操作，刷新后数据仍正确 |
| 权限和事务 | 本人范围不越界，重复编码拒绝，旧版本编辑冲突，成功审计失败时业务回滚 |
| 页面和契约 | 三语、大整数、等待/失败提示正确，接口响应通过运行时检查 |
| 检查结果 | 格式和契约无漂移；规定测试发现预期用例，执行结果无失败或跳过 |
| 后续维护 | 记录采用的模板版本，变更说明准确，未执行的环境与检查明确 |

命令和故障定位见[常用命令与问题排查](05-常用命令与问题排查.md)，模板已有检查结果见[本地验收记录](reports/模板验收记录.md)。
