# 开发自查清单

提交前对照核对。依据见[开发规范](04-开发规范.md)与[工程要求与命令](06-工程要求与命令.md)。

| 核对内容 | 判断方法 |
| --- | --- |
| 模块与分层 | 包结构、类名后缀符合[代码结构](03-代码结构.md)；`ArchitectureTest` 通过 |
| 接口契约 | 路径、Result 信封、字符串 ID/版本、独立错误码号段；OpenAPI 已导出并重新生成前端类型 |
| 权限与范围 | 主体来自服务端会话；服务用例检查权限；Mapper 语句准确登记数据范围；不可见与不存在同为 404 |
| 事务与并发 | READ_COMMITTED、加锁顺序、唯一约束、`id + version` 乐观锁，冲突返回 409 |
| 审计 | 受控字段白名单，成功审计与业务同事务，审计失败回滚 |
| 数据库 | 新增迁移 `V{n}__*.sql`，未改写已发布迁移；SQL 参数绑定、排序白名单 |
| 前端 | 函数组件、strict TS、TanStack Query key 含用户与授权版本、三语同步、状态呈现完整 |
| 秘密与日志 | 无默认账号或密钥，秘密不进入代码、日志、URL、截图 |
| 格式与测试 | `tools\format.bat check` 无差异；测试发现预期用例，失败/跳过为 0；未执行的环境如实说明 |
