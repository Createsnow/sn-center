## 显式隔离的旧库入口

`legacy-snapshot.ps1`、`legacy-stage.ps1`、`legacy-master.ps1`、`legacy-inventory.ps1` 及对应 CLI/Legacy* 实现全部保留。只有显式命令行参数进入离线模式，不从普通 Web 启动自动运行；源/目标连接、schema 白名单、时区和 UUID 必须明确，后三项默认 dry-run。支持 `-JarPath` 指定当前验收 JAR。

源契约仍限定 `sn-python-repository-v1` 的 19 表/254 字段，拒绝未知结构，不能把新原型新增表视为已支持。目标识别已增加 V19；完整参数、停用账号规则及受限 IMPORT 边界保留于[旧库契约原文](../archive/python-migration/docs/16-旧库快照暂存与主数据迁移.md)，其中 V17 目标描述是旧阶段状态，应结合本轮[补迁契约](../business/SN补迁契约.md)。

保留原因：历史合成演练可追溯，将来明确重新授权的数据恢复可使用已受检工具。当前用户确认不搬历史，故从 README 日常命令移出；不把删除 CLI 作为迁移完成条件。

明确前缀的 PBKDF2-120k 读取升级、旧错误映射、历史快照 NULL 与旧数据来源标记保留。它们参与兼容、读取或恢复，不因 `legacy` 命名删除。新密码仍用 PBKDF2-600k；无标识哈希拒绝，导入账号不自动启用。

三份基线、旧工作包、阶段报告、截图/下载证据及原入口只移动到归档；原始字节核对与对应清单见[归档索引](../archive/python-migration/README.md)。未复制秘密、数据、备份或工具缓存；SN 业务模块、依赖和 Flyway 链原样保留。
