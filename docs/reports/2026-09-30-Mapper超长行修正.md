# Mapper超长行修正

日期：2026-09-30。承接[全工程格式规范化](2026-09-30-全工程代码格式规范化.md)，修正上一轮仍残留的Mapper超长SQL字符串。上一份报告及证据保持原样，本次修改留在本地工作区。

## 修改结果

- 扫描37份Mapper，修正前20份文件共90行超过100字符，最长458字符；修正后全部不超过100字符，超限为0。30份Mapper发生排版变化，包含`AcquireMapper`、`SnAuditMapper`、`SnWorkMapper`和`TransferMapper`。
- 将长字段列表、VALUES、SET赋值及动态SQL按逗号或子句边界拆为Java常量拼接。两个Mapper中的超长文本块转为保留原始换行的常量拼接；SQL内容、参数和查询条件保持。
- 关闭google-java-format的`reflowLongStrings`，保留显式字符串分段。统一格式器同时调整24份其他Java文件的拼接缩进；全项目声明与字符串值核验一致。
- Maven Checkstyle Plugin 3.6.0使用默认Checkstyle 9.3，仅检查主源码Mapper的`LineLength`，上限100，包含缩进、注释、字符串，不豁免长SQL。生成源码及资源不在检查范围。检查接入父POM的`validate`及`tools/format.ps1`两种模式。
