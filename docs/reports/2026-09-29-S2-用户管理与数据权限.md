## 实现

- 用户分页搜索、启停筛选、新增、编辑姓名/部门/已有角色、停用/重新启用和重置密码；工号不变、不提供删除。MapStruct 映射 DTO/Entity/VO，ID、版本和总数使用字符串，部门展示名称。
- 服务权限 + MyBatis SQL 范围。逐 statement ID、资源、操作权限及表列白名单，缺规则/上下文或解析失败拒绝；五类部门范围中 SELF 为账号本人，空范围返回空页。权限拦截先于分页，按最终 SQL 顺序绑定原参数和类型化 Long 值。
- READ_COMMITTED 管理事务先锁权限协调行，再锁操作者/目标，重新读取权限与版本。逐权限比较目标及拟授予权限的部门/工厂范围；普通管理权限不能重置更高权限账号，显式安全管理能力也不能授予自身没有的权限。本人停用/重置拒绝；最后管理员检查与并发缩权串行化；成功递增安全版本撤销旧会话。
- @OperLog 的业务字段白名单、实际 before/after diff、成功同事务审计和用例失败独立审计。审计存储故障真实注入后，账号新增整体回滚；密码/哈希/token 不进入 diff。
- React 三语用户页、菜单/按钮权限、当前授权菜单 API、本地组件白名单、授权版本缓存隔离、本人修改后重新登录。用户页懒加载；移动表格可横向滚动。
- 新增 V3__user_management_audit.sql，追加模块/操作类型及用户部门索引；开发库已升级，V1—V3 冻结，后续从 V4 开始。

范围执行参考 [MyBatis-Plus 官方数据权限说明](https://baomidou.com/en/plugins/data-permission/)；本工程额外实现了拒绝默认规则和参数重排，未沿用官方示例“缺失条件返回 null”的放行方式。框架没有引用 system/sn 实体或业务表；规则及存储端口由 system 提供。
