# S4 初始化、生成与分配迁移报告

本阶段实现 PI 起号/历史清单导入、来源订单上下文与预演、原子生成和整来源订单分配。旧 Python/Vue 工程与三份来源快照保持只读。范围与退出条件见 [S4工作包](../plans/2026-09-29-S4-初始化生成与分配.md)。

## 原页面与逻辑

- `/pi-init` 保留 PI 查询、快照/客户/规则/流水状态、一次起号、粘贴/CSV/TXT 首列清单、重复提示、可选工厂/客户/物料和初始化记录。起号与 SN 从输入到响应都保持字符串。未知历史号写 PRINTED，seqPi/seqDec/ruleVersionId 留空，不伪造流水。
- `/generate` 保留远程订单选择、订单/分录与规则/PI 水位、工厂+PI 汇总、准备号→分配两步、可调数量建议、预演范围/物料段、进度和生成/分配历史。订单页“去生成”已接通稳定 billId。重复物料和空物料不合并；分录/候选/历史均可翻页。
- 按基线纠正旧部分分配入口：页面数量只读，命令 expectedQuantity 必须等于全部当前待分配数量；不能选择其他工厂或按物料拆分。分配后是 TO_ACQUIRE。
- 中/英/越词条沿用旧页并补齐新任务、资源、过期和异常语义；个人语言偏好继续复用平台身份服务。浏览器只保存分账号/动作的 operationId，刷新先查询原操作；未知响应可以同载荷同号重试，不自动生成新号。

## 持久事实与事务

V8 首次于本机测试库 2026-09-29 23:40 应用并冻结，SHA256：`8F87D950EE0F77B1E0ADF400AEBDCCBFCA0F02D552604460818B28948B519F72`。V1—V7 不变。新增 sn_pi_counter、sn_preview、sn_work、sn_item、sn_key；当前 SN 明细为 p_history/p_future 范围分区，自动月分区维护仍在 S7。

护栏唯一键分别为当前 PI+完整 SN、流水归属 PI+十进制流水；UTF-8 二进制排序，空流水不参加第二项唯一。护栏 ID+月份定位到同事务写入的真实 SN 明细。来源系统/账套/单据/分录、显示单号、原 PI/组织/工厂和规则版本在生成时固定；当前工厂与来源工厂分离。

操作+QUEUED任务+固定输入+PI占用+预演绑定在同一个短提交事务。数据库操作号唯一约束和任务提交控制负责并发重放，已有操作在重新消耗预演前返回。PI 活跃占用同时限制初始化、生成和分配；不能凭 Redis 丢失重做。

执行持任务行/代次栅栏，再事务内锁当前授权，取快照发布控制、PI 控制、必要来源额度及规则版本。快照全局控制覆盖来源订单发布，不另做 ERP 请求；与规则编辑共同的授权协调锁保证 used 标记和编码修改的先后。每 500 枚批量 SQL 都参加同一执行事务，不分段提交。SN、双护栏、水位/锁定、来源账本、规则 used、业务结果、成功审计及任务/操作成功一起提交；任一异常整批回滚。进度独立事务，可停在 500 而业务生效量仍为 0。

预演绑定人、来源快照/分录、规则版本和内容摘要、基础水位/起号条件、数量、有效期。工作器重新校验；旧预演失效后需新预演。终态失败/取消同事务释放本任务 PI 占用，预演仍被消耗；可重试异常由原任务保留占用并按代次接管。失败审计独立保存，审计库故障不覆盖持久终态错误。

初始化在取 PI 锁前反解固定清单，锁内核对一次性条件与规则摘要；水位取原水位、起号−1、解析最大值的最大值。仅可解析历史引用将版本标 used。生成依稳定分录顺序消耗额度，快照移除、减少、重排不退还历史。计划量小于消耗明确显示异常，待分配的原组织/PI 与新快照不一致也阻止继续生成或改投。

分配固定成员只保存月份+不可变 ID；执行按相同稳定排序核对全部当前待分配集合，再核对生成时组织/工厂/PI。成功状态 TO_ACQUIRE、固定 allocationId、分录累计分配和结果同事务。重复操作返回原任务，不再次分配。
