新目录只复制 Git 跟踪文件，不复制秘密、账号、数据、Git 历史或运行环境。随后单独安装工具：为避免重复下载公开 JDK/Maven 包，复制了公开工具/依赖缓存；前端从 registry 执行 frozen-lockfile 安装。它不运行相邻工程文件，但这不是全新电脑/操作系统安装验收。
