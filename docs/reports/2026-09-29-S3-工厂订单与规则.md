# S3 工厂、订单与规则迁移报告

本阶段将旧SN的工厂、生产订单快照和编码规则迁入 `adtek-platform-sn`，保留三个独立页面及主要操作、字段和业务逻辑。依据三份v1.1基线和用户“保持原有页面和逻辑”的要求实施；不是完整SN迁移或生产验收结论。旧工程、旧库和三份来源原件保持只读。

## 后端与数据

六模块依赖和分层保持基线。SN拥有工厂、组织映射、用户工厂关系、订单头/稳定分录/同步记录/来源账本及规则头/版本；system通过类型化端口处理工厂资格，不读取SN Mapper。MapStruct负责实体与VO映射；所有业务身份、版本、数量、容量在HTTP保持字符串。

工厂范围逐权限执行，与部门独立；订单列表/COUNT/详情/统计/客户候选同范围，跨厂详情404，空绑定不扩全厂。写入先锁安全协调行和当前账号复核授权，再锁业务对象；资格变更与security_version、审计同事务。单有全厂读权限不能扩大局部同步写权限。平台管理与SN总部角色仍独立；初始化管理员兼有两者。

K3适配器经真实HTTP调用LoginByAppSecret、ExecuteBillQuery和View。完整分页在发布事务外执行，稳定单据/分录ID、字段一致性、数量、响应大小、页数和预算均验证；非法/小数数量不截断，后页失败不发布部分数据。发布比较开始版本，更新全量/单据范围、稳定账本和成功审计同事务；并发发布只一方成功。删除或重排分录不转移历史额度，合法空同步保留历史账本与最近成功时间。单据只有明确不存在码当合法空；组织拉取失败可保留映射并提示。

V7已应用于本机测试库，SHA256 `CB8C4DABA1CF0890F0681153CC182F685AC232D59B27A52014E538452CB74B48`，此后冻结。V1—V6与前阶段摘要对照，用户密码和数据卷保留。V7新增SN菜单并递增有关账号授权版本，使用当前密码重新登录即可。
