## 事务、授权与文件边界

framework拥有操作/任务/进度/文件/容量控制表，通过TaskHandler端口调用消费者；system拥有导出行快照和业务审计。@Idempotent仅标记数据库模板契约，并非任意方法上的自动AOP实现。Mapper内部语句与范围语句逐条登记，无包级豁免。

提交使用READ_COMMITTED事务，先锁容量控制行，登记操作、任务、固定快照、文件元数据和提交成功审计，最后再次核验授权；任何一步失败整体回滚。审计查询与导出分别要求system:audit:list和system:audit:export，两项范围取交集。快照一次有界SELECT取得，超过上限明确拒绝，不分页拼接变化中的源记录或静默截断。

领取为短事务；执行事务首先锁任务行，再复核owner/epoch/租约、预算和当前权限。持有的行锁使过期租约不能被其他工作器越过；成功业务审计、READY元数据、任务SUCCESS和操作SUCCEEDED同事务提交。进度采用无父行外键的独立表及新事务，不等待执行中的任务行，不代表业务已提交。失败处理在执行事务结束后重新锁任务并核验状态/代次，旧工作器和提交后迟到错误不能覆盖SUCCESS。

查询、重放、执行、取消、恢复及下载均重载当前账号与完整快照范围。不同主体无权查询他人的任务；权限收缩不继续暴露历史结果。下载验证同一文件句柄的长度与SHA256，随后每次最多64KiB读取前复核权限。响应未提交时可返回统一错误；已提交字节后只能中止输出并记录受控日志，不能承诺改写HTTP状态或追加JSON。

文件与MySQL不构成同一个原子事务。发布后数据库回滚时，恢复执行核对原产物并复用；源日志改变不影响既定快照。已有成功操作的文件重建只更新任务和文件状态，不重做导出成功审计。恢复摘要必须与原SHA256一致，校验失败不会先替换原文件。初次执行最终FAILED保持失败，用户需明确发起新操作；成功结果的文件恢复可开启新的有界恢复周期。

文件名只能是服务器生成的UUID.csv；拒绝路径逃逸、符号链接/NTFS联接，使用NOFOLLOW、真实路径归属检查。临时产物由当前写入者清理，重试只在持有任务锁时清理同任务残留；不实施全局孤儿文件或隔离文件保留期清理。多实例必须配置同一持久文件目录及受控权限；本次仅验证本机Windows文件系统。

## 实际接口与容量

| 接口 | 行为 |
| --- | --- |
| POST /api/v1/system/audit-exports | 显式起止时间、操作UUID和筛选；202返回原或新任务 |
| GET /api/v1/system/audit-exports/operations/{operationId} | 当前主体按原号查询 |
| GET /api/v1/tasks/{taskId} | 查询任务/操作/文件状态及进度 |
| POST /api/v1/tasks/{taskId}/cancel | 仅QUEUED且未领取可取消 |
| POST /api/v1/tasks/{taskId}/recover-file | 成功操作从原快照恢复文件 |
| GET /api/v1/files/{fileId} | 当前权限下载READY文件 |

默认导出窗口最近7天，单次最多31天、10000行和16MiB。每用户最多3个活动任务，全局1000；最大3次尝试、30秒租约、300秒预算、3秒重试等待。事务自身仍受30秒超时约束；上述容量是保护边界，不是吞吐或耗时承诺。

CSV为UTF-8/CRLF，固定列为id、created_at、user_id、actor_username、actor_dept_id、module、action、success、object_id、trace_id。保留完整ID字符串，自由文本防公式解释，不导出原始diff或秘密。电子表格软件自行推断CSV数字类型可能改变显示精度，本阶段未提供XLSX文本单元格保证。输入规范化固定字段顺序、UTC时刻和空筛选；请求追踪头不参与摘要，业务筛选中的日志traceId参与摘要。更多契约见[接口文档](../04-接口契约.md)。
