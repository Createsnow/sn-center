# 代码风格与格式 0.1.0

格式由工具统一，不手工争论排版。提交前执行 `tools\format.bat`，再执行 `tools\format.bat check` 确认无差异。

## 通用（.editorconfig）

- UTF-8、LF 换行、文件末尾保留换行、去除行尾空白（Markdown 除外）。
- 缩进使用空格：默认 2；Java 为 4。
- `.gitattributes` 固定文本文件换行：`*.bat`、`*.cmd` 使用 CRLF，其余使用 LF。

## Java

- Spotless + google-java-format **AOSP** 风格（4 空格缩进），自动排序 import，格式化 Javadoc；不自动重排长字符串。
- `mvn validate` 阶段执行 `spotless:check`，格式不符即构建失败。
- Mapper 接口（`**/mapper/*.java`）由 Checkstyle 限制单行 100 字符。
- 命名：类名后缀与包一致（Controller、Service、ServiceImpl、Mapper、Entity、DTO、Query、VO、Convert）；常量全大写下划线。
- 包说明写在 `package-info.java`，公开 Service 与端口写 Javadoc。

## Mapper XML

- 两空格层级缩进，SQL 按子句人工排版；Spotless 只统一空白、制表符与末尾换行，不改写 SQL。
- 小于号写 `&lt;`；namespace 与语句 id 规则见[开发规范](04-开发规范.md)。

## POM

- sortpom 统一 POM 元素顺序与 2 空格缩进；不排序 properties、modules 与 executions。

## TypeScript / React

- Prettier：单引号、尾随逗号、`printWidth` 100。
- ESLint：`@eslint/js` 推荐规则 + typescript-eslint 推荐规则 + react-hooks + react-refresh，`--max-warnings 0`；禁止 `any`。
- tsconfig：`strict`、`noUncheckedIndexedAccess`、`noUnusedLocals`、`noUnusedParameters`、`verbatimModuleSyntax`，类型导入使用 `import type`。
- 组件文件 PascalCase（`XxxPage.tsx`），其他模块 camelCase（`queryClient.ts`）；每个组件文件只导出组件（常量除外）。
- 生成目录 `src/api/generated/`、`openapi/` 与锁文件不参与 lint/format。

## 配置文件

- `.gitlab-ci.yml`、`deploy/*.yml|json`、`application*.yml`、`tools/*.mjs` 由 Prettier 统一格式（`pnpm format:config` / `pnpm format:config:check`）。

## 脚本

- 不使用 PowerShell 脚本。Windows 工具为 `tools\*.bat`，Linux 部署脚本为 POSIX `sh`，跨平台逻辑写成 Node `*.mjs`。
- 批处理：首行 `@echo off`，随后 `setlocal`；只用 ASCII 字符（避免 cmd 代码页导致中文乱码）；从 `%~dp0` 推导工程路径，可在任意目录调用；调用 `mvn`、`corepack` 等 `.cmd` 程序必须加 `call`；每一步检查失败并以非 0 退出码结束。
- Shell：`#!/bin/sh` + `set -eu`，不使用 bash 专有语法，不回显秘密。
