# S2 系统配置切片

承接用户管理样板，继续实现迁移方案 F-03 的角色、菜单、部门、字典管理。遵守三份冻结 v1.1 基线，修改范围仅限新工程。

## 交付边界

- 角色新增/编辑/启停、五类范围、菜单及自定义部门绑定，精确 ID 与乐观锁版本。
- 部门 parent_id 树、父节点有效性、环检测、启用引用保护及范围变更传播。
- 菜单 M/C/F、固定本地组件与路径、权限标识不可变、目录关系和启停。
- 字典类型和值、三语名称、唯一约束、排序、停用保留引用。
- READ_COMMITTED 协调事务、授权前后比较、受影响账号版本撤销、INSERT/UPDATE 实际白名单审计。
- OpenAPI 类型、运行时守卫、三语 React 页、真实隔离 HTTP/数据库/浏览器测试。

全局配置要求对应权限及 ALL 范围的显式安全管理权限。配置目录没有所属部门；不得借新增表级伪范围制造越权。业务局部管理员不能维护全局配置。共享角色委派须有每项权限的 ALL 部门范围，工厂资格独立核验；此阶段不实现局部角色委派。

## 验证与限制

覆盖共享角色缩权撤销、旧版本冲突、越权授予、最后管理员/本人保护、部门移动/环/引用、菜单组件白名单/不可变权限、字典唯一性/三语/停用、审计故障回滚、并发写冲突及真实三语页面。基础认证/用户管理回归继续执行。

当前配置列表最多 1000 项，关系集合最多 100 项；超过明确拒绝。授权重算锁定全部账号，需在大规模上线前压测。没有物理删除、运行时自定义代码/路由或任意新增后端权限；新业务权限随对应后端用例和 Flyway 交付。审计查询、HTTP 入口失败审计、持久操作号/任务/文件及 S3—S8 仍是后续范围。人工 Security/SQL/权限边界审查仍待完成。
