# S2 持久操作、任务与文件工作包

状态：本阶段实现和自动化回归已完成，证据见[交付报告](../reports/2026-09-29-S2-持久任务与文件恢复.md)。依据三份冻结 v1.1 基线，承接用户“继续下一阶段”。用在线操作日志 CSV 导出作为首个真实消费者，不提前迁移 SN 打印或生成状态机。人工重点审查、强杀进程、多主机及性能验收仍待执行。

framework 拥有 sys_operation/sys_task/sys_task_progress/sys_file 和领取控制表，业务快照由 system 拥有。主体类型首期 USER；主体+动作+UUID operationId 唯一，规范化版本/载荷摘要固定。同号同载荷返回原任务，异载荷409；重放、工作器、查询、取消、恢复和下载都重新检查账号及完整快照范围。暂不开放管理员跨主体排障或外部调用方任务。

提交事务固定筛选和有界完整快照、操作及 QUEUED 任务。操作状态与任务/文件状态分开；操作成功结果引用不可改写。领取短事务 SKIP LOCKED，增加 owner/代次/租约；执行事务首先锁任务，再复核代次与授权，业务/成功审计/任务/操作最终结果一起提交。租约过期不能越过尚被执行事务持有的任务行锁。进度独立表不写任务控制行，不能把进度当作业务提交。失败回滚后独立核对终态和代次，再安排原任务恢复或终态失败。

工作器单个有界调度线程，不用无界队列；启动和周期扫描，最大尝试/整体预算有限。仅接受未领取 QUEUED 的取消，关闭停止领取并等待在途执行，强退由数据库恢复。HTTP 断连与停止轮询不取消任务。

导出固定快照最多10000行，文件最多16MiB；超限明确拒绝，不截断。生成临时文件、关闭/fsync/摘要校验、发布不可变服务器键，最后数据库 READY；发布后事务失败可核对同一产物继续。文件丢失/损坏仅从固定快照恢复，同一文件标识；损坏文件隔离保留，不按当前日志重新查询。路径不能由客户端提供，拒绝链接/越界；临时产物有明确关闭、失败清理和同任务恢复清理责任。文件根目录需持久保存，多实例必须共享同一目录。

CSV 是 UTF-8 程序交换格式，完整保留 ID 字符文本，不能保证电子表格软件自动识别精度；人名/模块等自由文本防公式解释。本阶段不提供 XLSX、任意上传、归档或 SN 导出。前端保留按用户分隔的必要操作 UUID，响应未知时查询原号，不自动换号重做；支持任务轮询、取消和恢复下载，三语错误/状态。

退出条件：真实 MySQL 并发同号/冲突/事务回滚、租约与旧代次竞争、提交后结果恢复、取消边界、进度不锁死任务、文件发布前后故障和丢失重建、路径/容量、当前权限收缩、真实浏览器提交/恢复/下载。保存命令、分层计数、截图及源码摘要。人工重点审查、强杀真实进程/多主机共享盘及性能验证如未执行须明确留待后续，不能由故障注入推断全部通过。
