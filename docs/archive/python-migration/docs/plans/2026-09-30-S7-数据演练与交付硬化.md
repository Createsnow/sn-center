## 维护与归档

月分区维护仅面向封闭表集合sn_item/sn_audit/sn_audit_archive，验证现有分区结构后生成受控DDL，支持p_future/pmax的已有兜底名称。DDL账户与页面运行账户分开；具备互斥、有限等待、运行记录与失败提示。未来月份预建及重复执行需用真实MySQL验证，不假设兜底为空。预演只清已过期且未被任务引用的记录，不删除已承载幂等、恢复或历史输入的事实。

审计默认永久保留；冷存储搬迁与删除保留期是不同决定。归档按整月固定边界执行复制、逐行内容/数量/摘要核对、可恢复备份证明、切读验证、移除在线数据；每个阶段可恢复，重复和冲突不能被INSERT IGNORE掩盖。没有可恢复证明时保留在线副本。SN、双唯一性护栏、来源额度、规则版本和固定领取/打印/转厂成员不随归档删除。

## 数据工具

以可识别版本的只读来源清单为起点，记录schema/来源历史、源时区、行数/分区/编码、孤儿/重复/未终态任务、文件路径与摘要。源只读快照与目标新Flyway链分开；工具明确source/target/runId和目标白名单，默认dry-run。检查点同时绑定来源摘要和映射版本，不允许悄悄换源续传。

主数据、身份/工厂/角色/语言、规则版本、水位/额度、SN/护栏、批次/打印/转厂、审计/归档和文件逐类迁移并核对。缺来源分录、缺固定历史、旧RUNNING不一致、旧幂等作用域及无时区时间必须形成差异清单，不能用当前值冒充历史或自动重新生成号。旧错误号和旧标识映射要明确契约；证据不足的在途业务阻止进入新写链路。

隔离演练先验证仓库已知schema，再验证每个被声明支持的版本；未知schema拒绝，不操作真实旧库。全量和断点续传均须证明总数/分组/摘要/双唯一性/水位额度/固定成员/当前状态/文件授权。不可重建的真实历史需要以后由业务提供证据或明确接受只读例外，不能由自动化擅自关闭。
