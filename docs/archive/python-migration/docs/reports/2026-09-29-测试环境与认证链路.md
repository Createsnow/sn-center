## 兼容问题与修正

- TypeScript 6.0.3 的严格安装因 openapi-typescript 7.13.0 要求 typescript@^5.x 失败。按 v1.1 允许的有证据回退锁定 5.9.3，未关闭 strict-peer-dependencies。保留 [原始 peer 失败日志](evidence/20260929-auth-runtime/typescript-6-peer-failure.txt)。
- AntD 两个传递依赖出现真实 TS2430 声明继承冲突，以 pnpm 的四处 .d.ts 小补丁修正；未修改运行时代码或关闭库声明检查，恢复条件见 [版本基线](../09-技术选型与版本基线.md)。
- 第一轮 HTTP 测试暴露标准认证链更新 CSRF Cookie 后旧令牌不能复用，客户端改为写入前获取当前令牌；不通过自动重试写入掩盖失败。
- 浏览器检查修正了移动端布局溢出及中文按钮无障碍名称。认证测试关闭了 Playwright 自动 DOM 失败快照；早期生成的本地失败上下文已脱敏，报告只保留无秘密截图。
- 发现 PowerShell Browser 参数与报告变量大小写冲突后改名，并实际重跑整套前端/浏览器门禁通过。
