## 业务与页面

转厂支持整PI、PI+物料（空串明确表示无物料）、单枚SN，以及快照/手工目标。申请整批冻结APPLYING；撤回或驳回恢复每枚原状态和原批次/打印指针；总部批准或直转到TO_ACQUIRE，清当前领取/打印指针，保留来源订单、流水归属、水位额度和所有固定历史。源/目标PI按稳定顺序占用，目标完整SN冲突、最后SQL块异常或审计失败均整批回滚。目标为空的客户/物料逐枚沿用，原厂与目标厂都可查固定历史，标签处置提示保留。

查询保留工厂、客户、PI、物料、状态、精确SN、来源单据和批次条件。同PI跨厂只读需要显式piAll及资格；分页游标绑定主体、授权版本与完整条件。CSV/XLSX按提交时固定成员和内容生成，读取与导出权限逐行同时检查。超出100000行/16MiB整体拒绝。文件故障不重复业务操作，只恢复同一个任务和字节一致的文件。

SN操作痕迹独立于平台管理日志，成功投影与业务同事务，失败事件独立提交。保存当时操作者/角色/工厂、来源、数量、状态、原操作号与原因；不拿当前SN和身份重建历史。生成完成是PENDING_ALLOC，取消只表示任务取消，不记录SN已生成；打印文件失败仍保留PRINTED。在线、归档和合并查询保留原始复合键，同一记录暂存两处不重复。导出固定日期窗；省略日期的同号请求跨午夜仍恢复原快照。默认永久保留；本阶段只提供归档读取，归档写入由S7承担。

首页恢复在途状态、待审批、上海业务日作业、最近任务和快捷入口，每项统计受当前权限约束。大计数和流水在API/前端均保持字符串。中/英/越页面、Ant Design组件语言及移动布局延续既有偏好。
