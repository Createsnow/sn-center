## 实现和实际结果

独立MySQL 8.4.11、Redis 8.4.7、Java 21 API及Nginx 1.30.5运行于container-test，HTTPS仅映射127.0.0.1:18443。API与Nginx非root、只读根目录、独立文件卷；Flyway单次迁移进程和维护账号与API分离。实际API账号CREATE TABLE返回1142拒绝。镜像固定digest见deploy/images.lock.json，版本实测见证据operations.json。

维护命令采用同连接命名锁、schema白名单、UUID与输入摘要、运行记录；月分区保留兜底已有行，失败可按现状继续。预演只清到期未绑定任务的记录。归档保留原始键/列，逐行长度帧SHA-256校验，永久保留。新增终结门禁逐项复查实际备份、恢复SQL/文件、浏览器结果和源身份，再锁定当前整月范围；在线移除与成功运行记录同事务提交。独立cron进程已经单次执行及重放验证，常驻调度profile交付但未自动启用；外部告警通道尚未配置。

实际备份`8f191650-f251-4b14-aab8-a1b22e117054`同时覆盖SQL和4个固定文件。恢复进入全新项目`adtek-sn-restore-938a69f3d632`、新MySQL server_uuid和独立卷，通过完整规范SQL、全部文件逐字节摘要，以及18444上真实登录、原SN查询、原CSV/XLSX下载；耗时49.321秒。Redis会话未备份，恢复后重新登录。原始SQL/tar和凭据留在受保护忽略目录，报告只附摘要。

隔离8月合成审计1条先复制、再备份恢复；终结操作`5c64018c-5454-4fd2-b71e-15e3ee4de87d`实际移除其在线副本，永久归档仍1条。原页面查询在线0、归档1、合并1，数量9007199254740993原样显示；同号重试返回原结果。此条明确标为演练夹具，不是真实业务历史。
