# 旧错误码逐项迁移登记

本表记录当前代码的实际行为，权威机器清单为 `backend/adtek-integration/src/main/resources/legacy/error-map-v1.json`，含旧 HTTP/params/三语、新整数/常量/HTTP/params/三语及原源码 SHA256。共97枚举项、4个字面量/默认值和1个无code的404边界。它不声称真实历史数据已导入。

同义汇总明确写在每行；旧消息不解析成新业务错误。部分旧输入限制已被v1.1模型替代，目标为空时保留历史失败，不改写成功。未识别码保留在受控档案，页面显示未知历史错误；任何原外部报文不能进入错误响应或直接HTML。
