# 工程要求与命令 0.1.0

## 环境

Windows PowerShell 7、Node 24、Git、Docker Desktop（Linux 引擎）、Edge。所有命令在工程根目录执行，脚本也支持从其他目录调用。工具脚本以 Windows 为基线；Linux 镜像不代表 Windows 工具可直接在 Linux 运行。

## 常用命令

| 命令 | 作用与成功判据 |
| --- | --- |
| `./tools/bootstrap-build.ps1` | 按 `build-tools.lock.json` 校验和准备项目内 JDK、Maven、pnpm |
| `./tools/bootstrap-format.ps1` | 准备固定版本 PSScriptAnalyzer |
| `./tools/pnpm.ps1 install --frozen-lockfile` | 按锁文件安装前端依赖，不允许临时升级 |
| `./tools/format.ps1` / `-Check` | 全仓格式化 / 检查（Java、XML、POM、前端、配置、PowerShell） |
| `./tools/verify.ps1` | 编译、架构测试、单元测试、打包；本次新报告 discovered > 0 且失败/跳过为 0 |
| `./tools/verify.ps1 -Integration` | 另外运行 `*IT` 集成测试（临时 Testcontainers MySQL/Redis） |
| `./tools/verify-web.ps1` | 契约检查（存在 OpenAPI 时）、lint、格式、单测、严格 TS、生产构建 |
| `./tools/verify-web.ps1 -Browser` | 另外运行 Playwright 浏览器测试 |
| `node tools/check-docs.mjs` | 文档本地链接全部有效 |
| `./tools/infra.ps1 start/status/check/stop` | 本地隔离 MySQL/Redis；首次 start 生成随机秘密；stop 保留卷 |
| `./tools/check-infra.ps1` | MySQL 认证查询、运行账号无 DDL、Redis 认证 PONG 且匿名 NOAUTH |
| `./tools/start-web.ps1` | 本地 Vite 开发服务器 `http://127.0.0.1:15183` |
| `./tools/build-images.ps1` | 已验证的 JAR 与 dist 构建本地 API/Web 镜像 |

本地端口：MySQL 33316、Redis 36389、API 18090、Web 15183；测试库 `adtek_template_test`，Compose 项目 `adtek-platform-template-test`。

## 创建新项目

```powershell
./tools/new-project.ps1 -Destination ../my-project -ProjectName my-project
```

- 目标目录必须不存在且位于模板之外；模板工作区必须干净。
- 只复制 Git 跟踪文件；替换项目名、数据库名与端口（默认 33326/36399/18100/15193，可用参数改写），生成 `template-origin.json` 记录来源版本与提交。
- 不复制账号、秘密、缓存、数据或 Git 历史。`com.adtek` 包名与 common/framework/system/server 模块名是框架约定，保持稳定。
- 新项目执行 bootstrap 与验证后 `git init`，提交代码与 `template-origin.json`。

## 测试要求

- 后端单元测试 `*Test.java`（surefire），集成测试 `*IT.java`（`-Pintegration`，failsafe）。
- 集成测试只使用临时 Testcontainers 或本工程隔离设施，不退回 H2/模拟数据库，不连接业务库执行破坏性测试。
- 每个写用例至少覆盖：正常流程、超长/非法输入、大于 2^53 的 ID、重复与并发创建、旧版本编辑冲突、越权读写、权限撤销后拒绝、审计失败回滚。
- 浏览器测试操作真实页面与独立 MySQL/Redis；禁止开启含凭据的 trace/storageState，截图不含秘密。
- 测试必须真实发现并执行预期用例：零发现、跳过或旧报告都不算通过。不得为了变绿跳过、禁用或隔离测试。
- `ArchitectureTest` 与 `locales.test.ts` 是规范门禁，不得删除或放宽。

## 提交与交付

- 提交前：`format.ps1`、`format.ps1 -Check`、`verify.ps1`（涉及数据库时 `-Integration`）、`verify-web.ps1`（涉及页面时 `-Browser`）、`check-docs.mjs`。
- 迁移文件发布后不可改写；接口变更同步导出 OpenAPI 并重新生成前端类型。
- 不提交秘密、`.env`、数据库卷、`.tools`、`node_modules`、`target`、`dist`、测试结果与运行日志。
- 报告实际执行的命令、版本、发现数与失败/跳过数，以及未执行的环境；远程 CI 结果单独说明，不以本地结果冒充。
- `.gitlab-ci.yml` 面向带 `windows-pwsh-docker` 标签的 Windows PowerShell runner（Node 24、Docker Linux 引擎、Edge），执行与本地相同的门禁。

## 常见问题

- Java/Maven 版本错误：先执行 bootstrap，通过 `tools/maven.ps1` 运行，不依赖系统 `JAVA_HOME`。
- Docker 不可达：检查 Docker Desktop Linux 引擎与 `docker info`；集成测试不会退回内存数据库。
- 端口占用：用 `Get-NetTCPConnection -LocalPort 18090` 等定位，不终止未知进程；新项目使用新端口参数。
- MySQL Access denied：核对 Compose 项目、数据库、秘密文件与首次创建卷时的凭据；改写秘密文件不会修改已有账号密码。不打印秘密、不自动删除卷。
- Flyway checksum 错误：恢复已发布 SQL 原文，用新版本迁移修正。
- 格式检查失败：执行 `./tools/format.ps1` 后审查差异再提交。
- 诊断日志写入 `tools/.runtime/`（已忽略），按 traceId 关联，不收集秘密。
