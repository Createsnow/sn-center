## 前端兼容记录

首次按基线尝试 TypeScript 6.0.3。pnpm 10.34.6 的 strict-peer-dependencies=true 检查返回 ERR_PNPM_PEER_DEP_ISSUES：openapi-typescript 7.13.0 要求 typescript@^5.x。保留原始失败摘要于本轮报告，因此工程统一锁定 5.9.3；没有将 5.9/6 留成长期任选项。恢复条件是生成工具正式支持 6.0 后，严格安装、类型、lint、类型生成、单元和浏览器全部通过。typescript-eslint 8.71.0 已声明支持 <6.1.0，不能将它说成回退原因。

开启 skipLibCheck=false 后，AntD 传递依赖的两个声明出现 TS2430：image 的分组 imageRender 回调与继承签名冲突，picker 的 defaultValue 可空性与 SharedTimeProps 冲突。frontend/patches 中仅修改 es/lib 的四处 .d.ts 继承：用 Omit 移除将重新定义的属性，保留各自真实签名；不改运行时代码、不关闭 strict、不增加 any。pnpm-workspace.yaml 和锁文件记录补丁及摘要，冻结安装已验证。它们是本项目维护的兼容补丁，不声称为上游已发布修复；依赖升级时应重新验证并撤除已无必要的补丁。

版本来源：npm 官方 registry 的精确包元数据；操作方法参考 [OpenAPI 类型生成](https://openapi-ts.dev/introduction)、[pnpm 补丁机制](https://pnpm.io/cli/patch)。完整补丁版本以 frontend/package.json / pnpm-lock.yaml 为准，不能用版本表代替锁文件。

S3未新增第三方依赖；K3通信使用Java21 HttpClient，测试协议夹具使用JDK HttpServer，仍锁既有MySQL/Redis、前后端版本和TS兼容例外。未以外部最新版本替换工程锁定版本。

S4同样未新增第三方依赖；Java精确long/BigInteger、MapStruct、现有持久任务和React Query承担实现。TS/AntD兼容例外与锁文件均保持。

S5新增Apache POI `poi-ooxml:5.5.1`用于XLSX文本产物，版本依据[官方发布页](https://poi.apache.org/download.cgi)，流式用法参考[SXSSFWorkbook API](https://poi.apache.org/apidocs/dev/org/apache/poi/xssf/streaming/SXSSFWorkbook.html)。锁定父POM属性；JDK21/Boot4.1.1/Jackson3编译与实际XLSX读写、固定摘要恢复已测。其余后端、前端及两个AntD声明补丁不变。ZIP核心属性/时间固定，恢复不受生成时间变化影响。

## 代码格式工具

Mapper行宽检查使用Maven Checkstyle Plugin 3.6.0及其固定默认Checkstyle 9.3，仅启用`LineLength`（100字符，包含字符串与注释），不解析Java语法，不增加应用运行依赖。配置限定主源码的Mapper目录，排除生成源码与资源；Maven `validate`和统一格式入口均执行该检查。配置依据[插件官方参数](https://maven.apache.org/plugins/maven-checkstyle-plugin/check-mojo.html)和[LineLength规则](https://checkstyle.org/checks/sizes/linelength.html)。
