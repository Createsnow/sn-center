# 金蝶ERP → SN系统 订单同步接口字段说明

SN 系统只读调用金蝶 K3 Cloud WebAPI，拉取**已审核**（`FDocumentStatus = 'C'`）的生产订单 `PRD_MO`，按物料行（单据编号 + 明细行号）写入快照表 `sn_prd_mo`，不写回金蝶。默认每 10 分钟按修改日期比对同步一次，另可按单据编号同步或全量重建。

## 接口

| 用途 | 金蝶服务 | 要点 |
| --- | --- | --- |
| 登录 | `AuthService.LoginByAppSecret` | 账套 Id、用户名、AppId、AppSecret、语言 2052；会话放 cookie `kdservice-sessionid` |
| 批量查询 | `DynamicFormService.ExecuteBillQuery` | `FilterString` 必含 `FDocumentStatus='C'`；每页 2000 行，按 `FBillNo, FTreeEntity_FEntryId` 排序翻页 |
| 单张查询 | `DynamicFormService.View` | `data.Number` = 单据编号；不是已审核或查无此单（`MsgCode = 10`）即从快照移出 |

批量查询 `FieldKeys`（顺序固定）：

```text
FBillNo,FDocumentStatus,F_ora_kh.FNumber,F_HX_PI,F_HX_PO,FPrdOrgId.FNumber,FPrdOrgId.FName,FTERM,FMaterialId.FNumber,FMaterialId.FName,Flength,FQty,FTreeEntity_FSeq,FModifyDate,FProductUnit,FPN,FCD,FAdtek,FMaterialId.FSpecification,FWorkShopID.FNumber,FWorkShopID.FName
```

最后 6 列是只显示的字段（见下方「只显示字段」）。金蝶不认这几列（查询报错）时，本系统改用前 15 列重新查询，这几列留空、同步照常；1 小时后再试带这几列。

## 表头字段

| SN 字段 | 含义 | 类型 | 金蝶字段（批量 / 单张） | 必填 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `bill_no` | 单据编号 | VARCHAR(64) | `FBillNo` / `BillNo` | 是 | 物料行标识的前半 |
| `customer_code` | 客户编码 | VARCHAR(64) | `F_ora_kh.FNumber` / `F_ora_Base.Number` | 否 | 基础资料 BD_Customer；没有时为空 |
| `pi` | PI | VARCHAR(64) | `F_HX_PI` | 是 | SN 按 PI 流水编号 |
| `po` | PO | VARCHAR(128) | `F_HX_PO` | 否 | 只显示 |
| `org_code` | 生产组织编码 | VARCHAR(64) | `FPrdOrgId.FNumber` / `PrdOrgId.Number` | 是 | 号的归属按它 |
| `org_name` | 生产组织 | VARCHAR(128) | `FPrdOrgId.FName` / `PrdOrgId.Name` | 是 | 取简体中文（2052） |
| `modify_time` | 修改日期 | DATETIME | `FModifyDate` / `ModifyDate` | 是 | 比对同步依据，明细变更时也更新 |

单据状态 `FDocumentStatus` 只用于筛选已审核，不入库。

## 明细字段

取自分录 `TreeEntity`，一条分录一行，不按明细业务状态过滤。

| SN 字段 | 含义 | 类型 | 金蝶字段（批量 / 单张） | 必填 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `seq` | 明细行号 | INT | `FTreeEntity_FSeq` / `Seq` | 是 | 物料行标识的后半 |
| `attach_no` | 附件项次 | VARCHAR(64) | `FTERM` | 生成前必填 | 金蝶为空时在页面补填，不写回金蝶 |
| `material_code` | 物料编码 | VARCHAR(64) | `FMaterialId.FNumber` / `MaterialId.Number` | 否 | |
| `material_name` | 物料名称 | VARCHAR(255) | `FMaterialId.FName` / `MaterialId.Name` | 否 | 取简体中文（2052） |
| `length_raw` | 米数 | VARCHAR(64) | `Flength` | 否 | 字符串原样写入 SN（含中文也照用，可在页面改）；为空时 SN 规则带米数须在页面填 |
| `unit` | 产品单位 | VARCHAR(64) | `FProductUnit` | SN 规则带单位时必填 | 文本字段，原样写入 SN（含中文也照用，可在页面改）；为空时须在页面填（如 M、PCS） |
| `qty` | 数量 | DECIMAL(18,4) | `FQty` / `Qty` | 是 | 带小数时不能按整数部分生成（现代码截取整数，待改） |

### 只显示字段

订单页、生成页、生产部门页显示用，不参与比对同步、生成、变更提醒。

| SN 字段 | 含义 | 类型 | 金蝶字段（批量 / 单张） | 说明 |
| --- | --- | --- | --- | --- |
| `customer_pn` | 客户 P/N | VARCHAR(128) | `FPN` | 明细文本 |
| `customer_desc` | 客户产品描述 | VARCHAR(500) | `FCD` | 明细文本（客户描述） |
| `spec_desc` | 规格描述 | VARCHAR(500) | `FAdtek` | 明细文本（Adtek 规格描述） |
| `material_spec` | 规格型号 | VARCHAR(500) | `FMaterialId.FSpecification` / `MaterialId.Specification` | 物料规格型号，取简体中文 |
| `dept_code` | 生产部门编码 | VARCHAR(64) | `FWorkShopID.FNumber` / `WorkShopID.Number` | 明细「生产车间」，基础资料 BD_Department |
| `dept_name` | 生产部门 | VARCHAR(128) | `FWorkShopID.FName` / `WorkShopID.Name` | 取简体中文 |

所有文本去首尾空格，基础资料为 null 视为空，超长按列宽截断。
