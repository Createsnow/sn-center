## 常见失败

- Java 找不到/版本错误：先 bootstrap，使用 tools/maven.ps1，不依赖系统 JAVA_HOME。工具锁丢失必须恢复批准文件。
- Windows Maven/HTTP 子进程 connect 失败：脚本设置本工程短 `.tools/tmp` 作为 JDK Unix-domain 套接字目录；不要修改系统 TEMP 或关闭测试。
- Docker 不可达：检查 Docker Desktop Linux 引擎与 `docker info`，测试不会退回 H2/模拟数据库。没有拉取权限时修复网络后重试。
- 端口占用：查看 `Get-NetTCPConnection -LocalPort 18090` 等；不要终止未知项目进程。创建新项目时用新端口参数；既有项目同步 Vite/环境/健康检查。
- MySQL Access denied：核对 Compose 项目、数据库、Secret 文件和初次创建卷时的凭据；本地文件重写不等于账号密码已更新。不要打印秘密或自动删除卷。
- Flyway checksum 错误：恢复已发布 SQL 原文，用新版本迁移，禁止 clean/baseline 自动掩盖差异。
- 登录 429：达到失败锁定/入口预算，按返回等待；管理员停用/版本变化会使旧会话失效。Redis 不可用返回依赖失败，不能放行。
- 新接口 403/500：先核对权限码、DataScope、准确 Mapper statement 注册和当前角色范围，不关闭全局拦截器排查。
- 编辑 409：按设备错误码区分重复编码、旧版本和缺部门；刷新并重新编辑。
- 契约漂移：运行 RuntimeIT 或本地 export-api，审查 JSON，再 api:generate；不能手写生成 TS 消除编译错误。
- 浏览器失败：查看 frontend/test-results/template-playwright.log、browser.json 和无秘密截图。禁止启用含凭据的 trace/storageState。失败日志保留，修复后重新执行。

生成诊断日志时使用 `*> tools/.runtime/自定义名称.log`，先创建该目录；它被 Git 忽略。按 traceId 关联，不收集密码、Cookie、Authorization、原库配置或数据库完整转储。
