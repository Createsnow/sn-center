# 文档导航

本目录共 8 份文档。它们有意保留了一部分重叠（例如 ER 图、接口清单在多份里都有），以便每份都能单独交给对应的读者；但**每个主题只有一份是权威来源**，其余只是摘要，冲突时以权威来源和代码为准。

## 1. 各文档的定位

| 文档 | 一句话 | 主要读者 | 篇幅 |
| --- | --- | --- | --- |
| [需求说明（修订版）](多工厂SN防重管控-需求说明（修订版）.md) | 业务口径：角色、SN 与 PI、额度、领取、转厂、留痕；附录列出按经验补充、待业务确认的项 | 业务方、项目负责人、测试 | 短 |
| [系统技术方案](系统技术方案.md)（另有 [Word 版](系统技术方案.docx)） | 正式评审稿：总体 / 数据 / 功能 / 非功能设计、风险；**附录 A 是完整配置项清单** | 评审、项目负责人、运维 | 长 |
| [关键节点说明](关键节点说明.md) | 同步 → 预演 → 生成 → 分配 → 领取打印 → 转厂 → 查询，每个节点「谁、在哪、进入、做完、下一步」；断点续做 | 业务方、现场实施、新成员 | 中 |

## 3. 按角色的阅读顺序

- **业务方 / 新成员**：需求说明 → 关键节点说明。
- **评审**：系统技术方案（含附录）→ 接口、数据与架构 §5（POC 与分区决定）。
- **开发**：README → 技术文档 → 数据库表设计；改错误码看技术文档 §10。
- **运维 / 实施**：部署说明书 → 系统技术方案附录 A、4.5、4.8。
- **MES 对接方**：只需要 MES 对接接口文档。

## 4. 改代码时要同步的文档

| 改了什么 | 需要同步 |
| --- | --- |
| 建表脚本 / 新增迁移 | 数据库表设计；部署说明书 8.1 的表清单与 `DROP TABLE` 语句；涉及 ER 时更新系统技术方案的图（`images/系统技术方案/*.drawio`） |
| 新增 / 修改接口 | 技术文档 §8；对外接口另改 MES 对接接口文档与接口数据与架构 §3 |
| 新增配置项 | `.env.example`、系统技术方案附录 A；常用项再加到技术文档 §11 / 部署说明书 §2 |
| 新增错误码 | `frontend/scripts/error_messages.py` 后运行 `gen_locales.py`；对外接口会返回的再加到 MES 文档 §8 |
| 痕迹动作 | 数据库表设计 §4.16 的 `action` 取值表 |
| 业务口径变化 | 需求说明 → 关键节点说明 → 技术文档 §9 |

`系统技术方案.md` 改动后重新生成 Word 版（仓库根目录）：

```bash
uv run --with pypandoc_binary --with python-docx --with pillow --with pymupdf python docs/build_tech_docx.py
```

装有 LibreOffice 时目录带页码，否则只有标题。图的源文件是 `images/系统技术方案/*.drawio`（draw.io / diagrams.net 编辑后导出同名 PNG、SVG）。
