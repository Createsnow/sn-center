# S4 初始化、生成与分配工作包

依据三份冻结 v1.1 基线，承接 S3。旧工程只读，保留 PiInit 和 Generate 的页面结构、起号/历史导入、预演、准备号与分配两步流程；整单分配按迁移方案纠正旧版部分数量入口。

交付范围：V8 的 PI 控制行、SN 双护栏和按月分区明细、预演、固定任务输入和业务结果；三个持久命令（初始化、生成、整单分配）；查询上下文、历史、三语页面与精确字符串输入；真实 MySQL/Redis/HTTP 与浏览器回归。

并发边界：沿用任务执行行/代次栅栏，事务内复核当前主体。业务锁按安全授权协调、快照发布控制、PI 控制、来源额度、规则版本、业务头、固定 SN 成员与护栏取得。短提交事务同时建立操作、任务、PI 活跃占用和预演绑定；同操作号重放在重新检查预演前返回原任务。业务成功、任务/操作结果和审计同事务，进度独立且不代表提交。终态失败/取消释放本任务的 PI 占用，不释放预演绑定。

生成按稳定来源分录顺序切段，重复/空物料保留。预演绑定人、快照、规则内容、水位、起号条件和数量；任一业务条件变化需重新预演。减少计划量低于历史消耗为异常；完整 SN 或流水冲突整批回滚，不跳号、不退历史额度。分配固定成员及生成时的生产组织，整批当前待分配，生产组织变化不能改投新厂。

初始化在首次生成前一次完成，可仅起号、仅清单或二者都有。解析清单后执行，未解析号保留流水空值并写 PRINTED；水位取已有值、起号减一和解析最大流水的最大值。数据库双唯一约束为最终护栏。输入数量/字节阈值是可配置资源准入，页面 10000 是可调建议量，不是业务限额。

退出核验：精确大整数、一次初始化、规则 used、失败原子回滚、同操作并发、同 PI 占用、预演失效、来源额度、整单固定成员、任务重放/过期代次、授权撤销；保留旧页布局与三语，浏览器刷新可查询原操作。真实进程 kill、多主机、吞吐与正式人工验收单列，不以单元测试替代。
