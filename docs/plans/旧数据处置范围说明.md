# 旧数据处置范围说明

日期：2026-10-04；决定：DEC-20261004-001。

用户已在当前执行会话明确选择：**仅新建隔离测试数据；保留原型原库，不搬历史数据。**

因此本轮不导入旧账号、主数据、库存、生成额度、领取/打印/转厂历史、审计、旧请求号或历史文件。不连接原型业务数据库作测试，不修改或删除原型目录、原库和文件。SN 已有开发/容器测试数据同样不通过清空方式重建。

验证数据由一次性 MySQL/Redis 测试容器和独立模板空库产生；测试数据包含高精度流水、权限差异、冲突和固定成员等场景，但不冒充真实历史数据。

原有 19 表来源识别及有限库存迁移工具继续保留。新原型修改了初始化 SQL，增加定时设置表及 PI 已选规则字段；不能把新结构当作原 19 表/254 字段来源兼容。工具应继续严格拒绝未支持版本，不为本轮功能补迁扩张旧 ETL 能力。

历史数据结论：**本轮不适用，基于用户明确范围决定**。完整历史转换（F-29）的实现限制仍保留在当前待办中；若将来需要搬迁，必须重新确认源 schema、时区、脱敏数据及文件证据并单独演练。

该决定不代表生产切换就绪，不替代真实 ERP/MES 联调、运行条件、备份恢复和业务签字。
